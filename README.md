# Prisbel Compras IA (Bella)

Leia o CLAUDE.md — é o contexto completo do projeto para o Claude Code.

Início rápido:
1. `cp .env.example .env` e preencha a N8N_API_KEY (n8n → Settings → n8n API).
2. `git init && git add -A && git commit -m "importa projeto Bella"`
3. Abra o Claude Code nesta pasta (`claude`) e peça, por exemplo:
   "Exporte os workflows vivos via API do n8n e compare com os da pasta workflows/".
